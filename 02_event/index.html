[jQuery 스타일변경 메서드]

  1. $("선택자").css() -> 프로그램적으로 css 접근 함수
  2. $("선택자").show() -> 숨겨져있는 요소를 보이게 하는 함수
  3. $("선택자").hide() -> 선택자 숨기는 함수
  4. $("선택자").toggle() -> 클릭시 보였다 안보였다 하는 함수
  5. $("선택자").width() -> 프로그램적으로 가로 사이즈 조절 함수
  6. $("선택자").height() -> 프로그램적으로 세로 사이즈 조절 함수
